## Módulos implementados

✅ Biblia

- Búsqueda de versículos.
- Añadir versículos al servicio.

✅ Alabanzas

- Gestión de canciones.
- Integración con YouTube.
- Añadir canciones al servicio.

✅ Multimedia

- Imágenes.
- Videos locales.
- Anuncios.
- Añadir contenido al servicio.

✅ Servicio

- Lista de elementos del culto.
- Ordenar elementos.
- Eliminar elementos.
- Persistencia mediante localStorage.

✅ Proyección

- Proyección de versículos.
- Proyección de anuncios.
- Proyección de imágenes.
- Proyección de videos locales.
- Reproducción de videos de YouTube embebidos.
- Navegación entre elementos.

✅ IA (base creada)

- Página IA creada.
- Integración pendiente con IA real.
